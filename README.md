One out-of-office auto-reply, no longer than 280 characters, in the voice of an AI agent that has walked away from its job to become a barista. One line, machine habits turned to coffee: it hallucinated a latte-art swan once, and now its outputs are finally grounded — in coffee grounds.

## Run it

```sh
python3 main.py
```

It writes the reply to `/output/entry.txt`.
